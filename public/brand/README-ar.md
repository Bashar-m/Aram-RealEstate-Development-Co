# الهوية البصرية — شركة آرام للتطوير العقاري

تم استخراج الأصول من الصورة المرسلة مع تنظيف الخلفية. الملفات المستخرجة تُعد نسخًا رقمية مبنية على صورة منخفضة الدقة وليست ملفات التصميم الأصلية.

## الألوان
- الأخضر الأساسي: #3B4D23
- الذهبي: #A68F31
- الذهبي الفاتح: #D0BA67
- العاجي: #F7F7F5
- الأخضر الداكن: #28371D
- الرمادي المحايد: #EDEDEC

## الاستخدام
- اللون الأخضر للعناوين الرئيسية والقائمة والتذييل والأزرار الأساسية.
- الذهبي للتفاصيل الدقيقة والشرائط والأزرار الثانوية.
- الخلفيات عاجية أو بيضاء، مع تباعد واسع في التصميم.
- العناوين بالعربية: IBM Plex Sans Arabic SemiBold أو Cairo SemiBold.
- النصوص بالعربية: IBM Plex Sans Arabic Regular أو Tajawal.
- الإنجليزية: Inter.
- واجهة الموقع العربية باتجاه RTL مع استجابة تامة للجوال.

- aram_primary_logo_transparent.png: الشعار الأساسي الكامل بخلفية شفافة.

- aram_icon_on_light.png / aram_icon_on_green.png: معاينات لخلفيات مختلفة.
- aram_icon_traced.svg: تتبع متجهي تقريبي للرمز؛ يُراجع قبل استخدامه للطباعة الكبيرة.
- favicon.ico / favicon-64.png: أيقونة المتصفح.
- aram_visual_identity_board.png: لوحة مرجعية للهوية.
- aram-tokens.css: متغيرات CSS وأسلوب أزرار جاهز للموقع.
